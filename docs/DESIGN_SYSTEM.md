# نظام التصميم والهوية البصرية (Design System — Light & Green)

يتبنّى **AS_FIT** هوية بصرية خاصة باسم **Fitness Telemetry UI — Light & Green**: لوحة قياس صحية ورياضية تمنح المستخدم شعوراً بالهدوء والنقاء والنظام.

---

## 1. المبادئ الحاكمة للتصميم

1. **وضع فاتح نقي (`Light Mode Only`):** خلفية الصفحة ذات تدرج أخضر ربيعي خفيف وثابت (`canvas` → `canvas-deep`)، وتجلس فوقه البطاقات شفافة بحدود رفيعة (`border-line`) دون خلفيات بيضاء ثقيلة أو ظلال. الاستثناء الوحيد لـ `bg-surface` هو العناصر الطافية (القوائم المنسدلة وشريط التنقل السفلي للجوال).
2. **حظر الألوان الفاقعة والساخنة:** **يُمنع تماماً استخدام الأصفر والبرتقالي والأحمر وأي لون صارخ**. تتكون الهوية حصراً من درجات الأخضر الدلالي والرماديات الهادئة (`Slate`).
3. **المعنى بالنص لا باللون وحده:** تُميَّز حالات الانتباه والتجاوز بدرجات الرمادي الهادئ **مقرونة دائماً بنص وسم صريح**.
4. **لا ألوان خام في المكونات:** الألوان الافتراضية لـ Tailwind معطّلة عبر `--color-*: initial` في [src/styles/globals.css](../src/styles/globals.css) لإلزام الجميع باستخدام متغيرات `@theme` الدلالية فقط.

| الدور الدلالي | المتغير (Token) | القيمة المرجعية | الاستخدام الصحيح |

| خلفية التطبيق | `canvas` / `canvas-deep` | `#F7FCF8` / `#E8F6EC` | التدرج الثابت لخلفية `<body>` |
| الأسطح الطافية | `surface` | `#FFFFFF` | القوائم المنسدلة الطافية وشريط الجوال السفلي |
| الحدود الفاصلة | `line` | `#E2E8F0` | حدود البطاقات والحقول والفواصل |
| النص الأساسي / الثانوي | `ink` / `ink-muted` | `#0F172A` / `#64748B` | النصوص الرئيسية / التسميات والوحدات |
| الإنجاز والتعبئة | `brand` | `#22C55E` | أشرطة وحلقات التقدم والأيقونات (**لا للنص الصغير**) |
| الأزرار / النص الأخضر | `brand-strong` / `brand-ink` | `#16A34A` / `#15803D` | الأزرار الرئيسية / النصوص الخضراء المقروءة |

## 3. الخطوط، الوحدات العربية، وقواعد `RTL`

- **النصوص:** خط `Cairo` (`font-sans`). **الأرقام والأوقات:** خط `JetBrains Mono` (`font-mono tabular-nums`) بالأرقام اللاتينية عبر المكوّن `<Num />` أو داخل `<bdi>`.
- **الوحدات بالعربية دائماً:** `سعرة`، `غ`، `ملغ`، `ملغ/غ`، `مل`، `كغ`، `سم`، `س`، `د` (تبقى الرموز العلمية اللاتينية للمصطلحات مثل `BMR`، `TDEE`، `MET`، `WHR`، `EMA`).
- **الأصناف المنطقية حصراً (`RTL`):** استخدم `ms-*`، `me-*`، `ps-*`، `pe-*`، `start-*`، `end-*`، `text-start`، `text-end`، `border-s-*`، `rounded-e-*`. يُمنع تماماً `ml-*`، `mr-*`، `pl-*`، `pr-*`، `left-*`، `right-*`، `text-left`، `text-right` (يفحصها `pnpm check:conventions` آلياً).
